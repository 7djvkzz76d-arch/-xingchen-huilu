# Security Policy

## Scope

This repository is a static web game. Do not submit passwords, tokens, API keys, payment information, or other secrets in issues or pull requests.

## Reporting a vulnerability

If you discover a security vulnerability, avoid publishing exploit details in a public issue. Report it privately through the repository owner's GitHub security reporting channel if available.

## Response goals

We will prioritize reports that could:
- execute unauthorized code;
- expose credentials or private data;
- bypass production deployment controls;
- materially disrupt the public service.

The game itself stores local progress in the browser and does not require account credentials for the public web build.
