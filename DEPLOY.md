# Deployment checklist

1. Import this repository into Vercel.
2. Framework: Other/static.
3. Build command: empty.
4. Output directory: repository root.
5. Verify on iPhone Safari, Android Chrome and desktop browsers.
6. Check all three levels, touch input, tray overflow, restart, undo and persistence.
7. Confirm level 3 ends with the success celebration and does not loop back automatically.
